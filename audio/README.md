# Recordings for Hebrew practice

Save each clip in this folder as an MP3 using the filename below. Say each syllable once in a natural voice, with little silence at either end. The app plays two-letter prompts by playing the first syllable and then the second.

## First group

| Letter | Kamatz or Patach | Segol | Standalone letter |
| --- | --- | --- | --- |
| א | `ah.mp3` | `eh.mp3` | `aleph.mp3` |
| בּ | `bah.mp3` | `beh.mp3` | `bet.mp3` |
| ב | `vah.mp3` | `veh.mp3` | `vet.mp3` |
| ג | `gah.mp3` | `geh.mp3` | `gimmel.mp3` |
| ד | `dah.mp3` | `deh.mp3` | `daled.mp3` |

For the standalone vowels, say the vowel sound and save it as `kamatz.mp3`, `patach.mp3`, or `segol.mp3`. For standalone letters, say the letter name or give a short pronunciation example.
